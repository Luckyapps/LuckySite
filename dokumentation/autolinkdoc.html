AutoLink Dokumentation 👋

Was ist das? Arten Definiern und verwalten von AutoLinks Attribute

Was ist AutoLink?

AutoLink ist ein System, um eine Einfache verwaltung von Links über eine Website hinweg zu ermöglichen. Dabei können alle Links von einer zentralen Stelle (einem JS-Object) gesteuert werden. Das umfasst z.B. den Pfad, den Namen, ... .

Hervorzuheben ist auch die einfache verwaltung von Links Sprachübergreifend. Denn in Kombination mit dem Linkmanager kann der Link automatisch in der entsprechenden Sprache angezeigt werden.

Bei aller Einfachheit bleibt allerdings trotzdem ein großer anpassungsspielraum durch viele Einstellungsmölichkeiten für bestimmte Links.

Arten von Autolinks

Es werden grundsätzlich zwei Arten von AutoLinks unterschieden: onsite und offsite. Das bedeutet es gibt Links zu Seiten auf der eigenen Website und "freie" Links.

onsite autoLinks

onsite autoLinks sind autoLinks, die auf einen andere Seite der eigenen Website verweisen. Sie sind die Standard-Linkart

Definition

onsite autoLinks werden in der sitemap.js im sitemap Object definiert.

offsite autoLinks

offsite autoLinks sind autoLinks, die auf irgendetwas verweisen und können frei gewählt werden.

Definition

offsite autoLinks werden in der linkmanager.js im ahorn.autoLinks Object definiert.

Definieren und verwalten von AutoLinks

Um autoLinks zu verwenden müssen diese in der sitemap.js, oder der linkmanager.js definiert werden.

Format

Für offsite autoLinks muss ein Object der folgenden Art in ahorn.autoLinks hinzugefügt werden:

    template: {
        name: "", //Standard Anzeigename
        href: "", //Standard Link
        download_name: "", //Name und Dateipräfix der Downloaddatei (optional)
        download_force: true, //Verhindert downloadToLink (optional)
        langs: { //Hier können Sprachspezifische änderungen definiert werden (optional)
            de: { //Id der Sprache
                name: "", //Parameter, die geändert werden sollen
                href: ""
            },
            en: {
                name: "",
                href: "",
                download_name: ""
            }
        }
    },

Attribute

  • Name
    • Standard Anzeigename
  • href
    • Standard Link
  • download_name
    • optional
    • Nur für Downloadlinks
    • Name und Dateipräfix der Downloaddatei
  • download_force
    • optional
    • Nur für Downloadlinks
    • Überschreibt die downloadToLink Einstellung.
  • langs
    • optional
    • Hier können Werte für bestimmte Sprachen angepasst werden.
    • Hier definierte Werte überschreiben die default Werte.

AutoLink Attribute

autoLink-type

Gibt die Art des autoLinks an.

Mögliche Werte sind:

  • onsite
    • Standard Link auf der selben Seite
    • Kann weggelassen werden.
  • onsiteNOa
    • Ist ein onsite Link, der aber kein a-HTML-Element ist (<a>)
  • offsite
    • Ist ein offsite Link
    • offsite Links erkennen automatisch, ob es sich um ein a-HTML-Element (<a>) handelt und stellen automatisch um.
    • Ist ein offsite Link kein a-HTML-Element (<a>) wird der Text standardmäßig nicht automatisch gesetzt.
  • download
    • Ist ein offsite Link mit Download-Funktion

autoLink-id

Ist die Einzigartige Id des autoLinks mit der er auch definiert ist. Jede id darf nur einmal verwendet werden. In Ausnahmefällen kann für einen onsite und einen offsite Link die selbe id genutzt werden.

autoLink-lang

Normalerweise wird für den autoLink automatisch die Sprache der aktuellen Seite angewendet. Möchte man aber den Link für eine andere Sprache, kann man diese hier angeben.

Der Wert muss eine lang_id wie z.B. "de" oder "en" sein.

autoLink-keepText

Soll verhindert werden, dass bei einem normalen autoLink der Linktext automatisch gesetzt wird, muss dieses Attribut angegeben werden. Es ist kein Wert nötig (="" kann weggelassen werden.)

autoLink-setText

Setzt bei nicht a-HTML-Element (<a>) (z.B. bei autoLink-type="onsiteNOa" oder bei entsprechenden offsite Links) den Linktext trotzdem automatisch. Es ist kein Wert nötig (="" kann weggelassen werden.)
